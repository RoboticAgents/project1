# Team Evaluation Forms

This directory contains templates for the peer evaluation and self-reflection forms used in Project 1.

## Overview

Project 1 uses a **combination of team and individual assessment** (80% team product / 20% individual contribution) to ensure fair grading. The evaluation process includes:

1. **Peer Evaluation** - Teammates rate each other
2. **Self-Reflection** - Each student reflects on their own contribution
3. **Code Review** - Individual technical interview with instructor
4. **Repository Evidence** - Git commits and documentation

## Files in This Directory

- `peer-evaluation-template.md` - Template for creating the peer evaluation Google Form
- `self-reflection-template.md` - Template for creating the self-reflection Google Form

## Implementation Guide

### Step 1: Create Google Forms

1. Create two separate Google Forms based on the templates
2. Configure settings:
   - Limit to 1 response per person
   - Collect email addresses (Allegheny accounts)
   - Make responses private (only instructor can see)
   - Mark most questions as required

### Step 2: Share with Students

**When:** Share links 1 week before final deadline (around January 26)

**How to share:**
- Post links in Discord announcement
- Include in Canvas/LMS
- Mention in class

**Deadline:** Due with final project submission (February 3, 11:59 PM)

**Reminder:** Send a 24-hour reminder before deadline

### Step 3: Collect and Analyze Responses

1. **Export to Google Sheets** for easier analysis
2. **Calculate average peer evaluation scores** per student
3. **Read qualitative comments** for patterns and specific concerns
4. **Compare self-reflection with peer evaluations** for alignment
5. **Review with code review performance and git evidence**

### Step 4: Determine Individual Adjustments

Most teams where everyone contributes will receive the **same individual grade**.

**When to adjust:**
- Peer evaluations consistently rate someone low (avg < 3.0/5.0)
- Multiple teammates cite specific non-contribution
- Self-reflection contradicts all peer feedback
- Git history shows minimal commits
- Code review reveals lack of understanding

**Example scenarios:**

| Scenario | Action |
|----------|--------|
| All teammates rate 4-5, good self-awareness | No adjustment needed |
| One person rated 2-3 by all others, admits struggles | Reduce individual score by 0.3-0.5 pts |
| Person claims full contribution but peers disagree | Schedule follow-up meeting, review evidence |
| Extenuating circumstances documented (illness, etc.) | Consider context, possibly no penalty |

- Reflect on your own contributions and learning
- Honest self-assessment of your work
- Also CONFIDENTIAL
- Takes about 15-20 minutes

**Due: February 3, 11:59 PM** (same as project deadline)

- Complete them thoughtfully - this is not just a checkbox exercise

Both forms must be completed by each person to receive full credit.

Questions? Ask in Discord or come to office hours.

## Tips for Code Reviews

Use peer evaluation and self-reflection responses to inform your code review questions:

**If peer evals mention someone "didn't contribute to coding":**
- Ask them to explain ANY part of the code in detail
- Have them trace through what happens when a motor is commanded
- Ask about PWM, H-bridges, power systems

**If someone claims they did "everything":**
- Ask specific questions about tasks peers said they did
- Look at git blame to verify claims

**If someone admits they struggled:**
- Focus on what they DID learn
- Ask about the design and mechanics (not just code)
- Give credit for honest self-awareness

## Grading Formula

**Individual Score (1.6 points) = Code Review (1.0) + Peer Eval (0.3) + Self-Reflection (0.3)**

**Code Review (1.0 pt):**
- 1.0 = Excellent understanding, can explain everything
- 0.8 = Good understanding, minor gaps
- 0.6 = Adequate understanding, some confusion
- 0.4 = Poor understanding, significant gaps
- 0.0-0.3 = No understanding or no-show

**Peer Evaluation (0.3 pts):**
- Based on average peer scores (1-5 scale)
- 4.5-5.0 avg = 0.3 pts
- 3.5-4.4 avg = 0.25 pts
- 2.5-3.4 avg = 0.2 pts
- 1.5-2.4 avg = 0.1 pts
- <1.5 avg = 0 pts

**Self-Reflection (0.3 pts):**
- 0.3 = Thoughtful, honest, demonstrates learning
- 0.2 = Adequate reflection, some depth
- 0.1 = Superficial or defensive responses
- 0 = Not completed or entirely off-base

## Privacy and Ethics

**Important:**
- Peer evaluations are CONFIDENTIAL (not anonymous to you, but teammates won't see each other's)
- Never share individual evaluation responses with other students
- Use feedback constructively, not punitively
- If there are serious team issues, address them early (don't wait for evaluations)
- Document any meetings with students about contribution issues
