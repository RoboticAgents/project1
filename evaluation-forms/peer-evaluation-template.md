## Implementation Notes for Google Forms:

1. **Set up the form to repeat Section 2 for each team member:**
   - After Section 1, ask "How many teammates do you have (including yourself)?" [Number]
   - Use Google Forms' section branching or create separate sections for Teammate 1, Teammate 2, Teammate 3

2. **Settings to configure:**
   - ✓ Limit to 1 response (using Allegheny email)
   - ✓ Collect email addresses
   - ✓ Do NOT share responses with respondents
   - ✓ Only you (instructor) can see responses
   - Set as "Required" for most questions (except "Optional" ones)

3. **Sharing the form:**
   - Share link in announcement: "Complete by [date]"
   - Send reminder 24 hours before deadline
   - Mention this is REQUIRED for final grade

4. **After collecting responses:**
   - Export to spreadsheet
   - Calculate average scores per person
   - Read qualitative comments for patterns
   - Use to inform individual grade adjustments
