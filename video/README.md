# Video Demonstration

Place your final demonstration video in this directory, or provide a link below.

## Video Requirements

Your video should be **2-3 minutes** and include:

### Required Content

1. **Team Introduction (15-30 seconds)**
   - Team name and members
   - Brief project overview

2. **Robot Overview (30-45 seconds)**
   - Show robot from multiple angles
   - Point out key components:
     - Arduino
     - Motor driver
     - Motors and wheels
     - Battery and power switch
     - Any sensors or special features

3. **Live Demonstration (60-90 seconds)**
   - Show all required behaviors:
     - Forward movement
     - Backward movement
     - Left turn
     - Right turn
     - Autonomous behavior
   - Film from angle where motion is clear
   - Include multiple takes if needed

4. **Closing (15-30 seconds)**
   - One interesting challenge you overcame
   - What you learned
   - What you're most proud of

### Technical Requirements

- **Format:** MP4, MOV, or AVI
- **Resolution:** 720p minimum (1080p preferred)
- **Audio:** Clear narration (built-in camera mic is fine)
- **File Size:** Under 500 MB (for GitHub) or upload to YouTube/Drive

### File Naming

If uploading directly:
- `team-[name]-robot-demo.mp4`

If using external hosting:
- Create a file `video-link.txt` with the URL

## Tips for a Great Video

- **Lighting:** Film in well-lit area
- **Stability:** Use a tripod or stable surface
- **Audio:** Minimize background noise
- **Multiple Takes:** It's OK to edit together multiple clips
- **Show Failures:** If something goes wrong, show it! Explain what happened

## Editing Software (Optional)

Free options:
- iMovie (Mac)
- Windows Photos (Windows)
- DaVinci Resolve (Mac/Windows/Linux)
- OpenShot (Mac/Windows/Linux)

## Upload Options

### Option 1: GitHub (If file < 100 MB)
```bash
git add video/team-name-demo.mp4
git commit -m "Add demonstration video"
git push
```

### Option 2: YouTube
1. Upload as unlisted video
2. Create `video-link.txt` with URL
3. Commit the text file

### Option 3: Google Drive / Dropbox
1. Upload video
2. Set sharing permissions (anyone with link can view)
3. Create `video-link.txt` with URL
4. Commit the text file
